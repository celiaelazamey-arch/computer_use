# Roadmap

This is a planning outline, not a claim that the listed capabilities exist.

1. Confirm product requirements, license, and threat model.
2. Define safe agent and tool boundaries before adding automation.
3. Select model and browser/computer integrations with explicit credential handling.
4. Add focused capabilities with tests, observability, and rollback guidance.
5. Create a first tagged release only after a stable scope and deployment path exist.
