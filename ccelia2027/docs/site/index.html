جارٍ فحص الخدمة
خطط. راجع. نفّذ.

ابحث في الويب،
بدليل واضح.

أنشئ خطة أولًا، راجعها، ثم اقرأ صفحة عامة بجلسة Playwright قصيرة. لا تسجيل دخول للمواقع أو تفاعل معها أو إرسال أو حذف أو تعديل. لا نشغّل JavaScript داخل الصفحات؛ قد لا يظهر المحتوى الذي يعتمد عليه.

سجل المحادثة يُحفظ في هذا المتصفح فقط. لا تكتب كلمات مرور أو أسرارًا، ولا تفتح رابطًا ينفذ إجراءً بمجرد تحميله.

خدمات التشغيل

النموذج: جارٍ الفحص

المتصفح: Cloudflare Browser Run · Playwright

النمط: قراءة فقط

كيف تعمل

١. النموذج ينشئ خطة منظمة.

٢. راجع الموقع والهدف قبل التشغيل.

٣. المتصفح السحابي يفتح الصفحة ويستخرج النص.

٤. النموذج يلخص النص الذي قُرئ بالفعل.

حماية الحصة والتكلفة

حجز داخلي محافظ: حتى ٥ محاولات متصفح في اليوم، دقيقتان محجوزتان لكل محاولة، و٢٨ استدعاء AI.

لا يوجد مزود احتياطي مدفوع. عند الحد أو الخطأ، تتوقف المهمة.

هذه الحدود لا تستبدل ضبط حساب Cloudflare على الخطة المجانية.

لا يُنفّذ التطبيق تسجيل الدخول للمواقع أو إرسال النماذج أو أي تغيير خارجي.
